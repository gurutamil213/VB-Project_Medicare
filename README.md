# Medicare Management System

A **VB.NET Windows Forms desktop application** for managing the day-to-day operations of a medical/pharmacy-style business. The project uses a **Microsoft Access (`.accdb`) database** for persistent storage and provides separate forms for customers, employees, stock, sales, records, and billing.

## 📌 Project Overview

The **Medicare Management System** is designed to simplify common management tasks in a medical store or healthcare-related business.

The application is built as a desktop application using:

- **Visual Basic .NET (VB.NET)**
- **Windows Forms**
- **Microsoft Access Database (`.accdb`)**
- **ADO.NET / DataSet-based database access**
- **Visual Studio**

The project contains multiple Windows Forms that are organized around different business functions.

## ✨ Features

### 👤 Customer Management
- Add and manage customer information
- View customer records
- Update existing customer details
- Delete or maintain customer records

### 👨‍💼 Employee Management
- Maintain employee information
- Add, view, update, and manage employee records

### 📦 Stock Management
- Manage medicine/product stock
- Maintain stock-related information
- Support inventory tracking for sales operations

### 💰 Sales Management
- Record sales transactions
- Manage sales-related information
- Connect sales operations with available stock/data

### 🧾 Billing
- Create and manage billing details
- Display transaction/billing information
- Support the sales-to-billing workflow

### 📋 Records
- Maintain and display stored business records
- Provide forms for viewing/managing application data

### 🖥️ Multi-Form Interface
- Uses a main MDI-style interface
- Separate forms are provided for individual modules
- Designed for a traditional Windows desktop workflow

## 🚀 Getting Started

### Prerequisites

Before running the project, make sure you have:

1. **Windows**
2. **Visual Studio** with Visual Basic / .NET desktop development support
3. **Microsoft Access** or the required Access Database Engine/ACE provider
4. The `medicare.accdb` database included with the project

### Installation

1. Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/medicare.git
```

2. Open the project folder.

3. Open:

```text
medicare.vbproj
```

in Visual Studio.

4. Make sure the project can locate:

```text
medicare.accdb
```

5. Check the database connection settings in:

```text
App.config
```

6. Build the project using **Build → Build Solution**.

7. Run the application using:

```text
Debug → Start Debugging
```

or press:

```text
F5
```

## 🗄️ Database

The application uses a Microsoft Access database:

```text
medicare.accdb
```

The database is intended to store the application's operational data, while the generated DataSet files provide strongly typed access to database-related structures.

### Database file location

For the simplest setup, keep the database in the project directory:

```text
medicare/
└── medicare.accdb
```

If the database is moved to another location, update the application's connection configuration accordingly.

> **Important:** The exact database connection provider/path can depend on the Visual Studio/.NET and Microsoft Access Database Engine installation on the machine running the application.
